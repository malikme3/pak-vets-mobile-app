# Pak Vets mobile app

## Add buttons

- Match the app's existing Add button style for the same action hierarchy. Reuse an existing button component or style where available. Keep the color, typography, corner radius, height, and icon placement consistent.
- Make a standalone primary Add button span the full available content width when the layout allows. Use compact buttons for toolbars, inline rows, and grouped actions where full width would disrupt the layout.
